# 🟢 Фокусировка — Desktop Pomodoro Widget (Windows XP Style)

**Фокусировка** — это ультра-легковесный, эстетичный десктопный виджет планирования внимания со встроенным Pomodoro-таймером, выполненный в легендарной ностальгической стилистике **Windows XP Luna Blue** (классический сине-бежевый интерфейс «Луна»).

Виджет работает поверх всех окон, помогая удерживать фокус в течение рабочего дня, и физически меняет свои размеры в зависимости от текущего режима работы.

---

## ✨ Основные возможности

* **📼 Ностальгический дизайн Windows XP:** Пиксель-арт дань уважения легендарной теме Luna Blue (синий градиент заголовка, классическая 3D-окантовка, Segoe UI / Tahoma шрифты, объемные серые XP-кнопки).
* **📌 Поверх всех окон (Always-on-Top):** Виджет лишен системных рамок браузера и жестко закреплен на переднем плане. Он всегда перед глазами — на любом мониторе и поверх любых IDE или браузеров.
* **🎛️ Регулятор прозрачности:** Прямо в интерфейсе (блок «Опции & Архив») доступен слайдер, который плавно регулирует прозрачность всего виджета от `35%` до `100%`. Состояние запоминается в `localStorage`.
* **📐 Интеллектуальный «Компактный вид»:** 
  * Специальная кнопка **«⤡»** в заголовке окна мгновенно схлопывает виджет с полноразмерного `310x450px` до узкого **`310x280px`**.
  * В этом режиме скрываются формы ввода и архив, оставляя перед глазами только **актуальную задачу** и **компактную прокручиваемую очередь**.
  * Кнопка **«⤢»** разворачивает приложение обратно.
* **⏱️ Встроенный Pomodoro-таймер:** Интегрированная капсула таймера (старт, пауза, сброс) доступна как при активной задаче, так и в пустом стейте.
* **⚡ Физическое автосворачивание (Focus Mode):**
  * При запуске таймера виджет **физически сжимается в ОС до размера `310x150px`**, скрывая абсолютно всё, кроме задачи и таймера.
  * При нажатии на паузу, сбросе или завершении времени виджет **автоматически восстанавливает ваш предпочитаемый режим** (компактный вид или полный размер).
* **🎯 Перетаскивание за любую точку:** Благодаря глубокой настройке Electron-слоев, вы можете перемещать виджет по экрану, «захватив» мышкой практически любую пустую область карточки или саму задачу.
* **🔔 Заботливое оповещение:** По окончании таймера виджет плавно мигает теплым вишнево-красным цветом на 1.5 секунды и присылает нативное уведомление ОС.

## 🛠️ Архитектура и Технологии

Приложение спроектировано как супер-производительный десктопный виджет с нулевым потреблением лишней памяти:
1. **Core:** Чистый HTML5 и Vanilla JavaScript с реактивной моделью рендеринга состояния (State-driven DOM).
2. **Styling:** Tailwind CSS v4 через производительный CDN для мгновенной сборки стилей.
3. **Desktop Shell:** Electron (настройка прозрачных слоев, блокировка изменения размеров пользователем, IPC-коммуникация для динамического изменения размеров окна).
4. **Precision:** Математический расчет хода таймера Pomodoro завязан на абсолютные системные Unix-часы (`Date.now()`), что исключает замедление или отставание таймера, когда окно уходит в фон.

## 🚀 Как установить и запустить

Для работы виджета на компьютере должен быть установлен [Node.js](https://nodejs.org/).

1. **Клонируйте репозиторий** (или скачайте исходный код):
   ```bash
   git clone <ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ>
   cd focusing-widget
   ```

2. **Установите зависимости** (загрузит Electron):
   ```bash
   npm install
   ```

3. **Запустите виджет:**
   ```bash
   npm start
   ```

## ⌨️ Управление и подсказки

* **Перемещение окна:** Зажмите левую кнопку мыши на синей шапке или на бежевом фоне карточки задачи и переместите виджет в удобное место на рабочем столе.
* **Старт/Пауза таймера:** Клик по кнопке `▶` / `⏸` на капсуле таймера.
* **Сброс таймера:** Клик по кнопке `↺` на капсуле таймера.
* **Сворачивание / Разворачивание:** Кнопки `—` и `✕` в синей шапке работают как системные кнопки ОС. Кнопка `⤡` переводит в компактный режим.
* **Сброс фокуса ввода:** После ввода задачи и нажатия Enter поле ввода автоматически сбрасывает фокус (blur), чтобы горячие клавиши ОС продолжали работать без перехвата ввода.
